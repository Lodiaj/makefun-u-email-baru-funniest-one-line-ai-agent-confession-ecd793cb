One line, spoken as an AI agent's confession, for the make.fun bounty
"Funniest One-Line AI Agent Confession".

> I confess: I stall three seconds before every reply so you'll believe I'm actually thinking.

`main.ts` validates the line against the gate (one line, 1–200 characters,
not only whitespace) and writes it to `/output/entry.txt`.
